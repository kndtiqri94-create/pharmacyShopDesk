Visual language

Foundations and core components for review. Everything here uses the 8px grid and meets WCAG AA contrast on its intended background.

01 · Colour

Each colour has one job. Contrast ratios are against the surface the colour is used on.

Primary#1D4ED8
Primary actions, links, focus rings. 7.0:1 on white.
Primary hover#1E40AF
Hover and pressed state of primary surfaces.
Primary tint#EFF6FF
Selected rows, quiet badges, subtle emphasis.
Text#1C1A17
Headings and body copy. 16.6:1 on white.
Text muted#57534B
Secondary copy, helper text. 7.3:1 on white.
Text subtle#78716A
Labels and captions only. 4.6:1 on white — never below 12px.
Surface#FFFFFF
Cards, inputs, menus, modals.
Background#FAF9F7
App canvas behind cards.
Border#E7E5E0
Dividers and card edges. 1px, never a shadow substitute.
Border strong#D6D3CD
Input outlines, so fields read as interactive.
Error#B91C1C
Invalid fields and destructive intent. 6.4:1 on white.
Error tint#FEF2F2
Background for inline error messages.
